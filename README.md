# 化学PDF校正ビューア（試作版）

PDFまたはPPTXをブラウザ内で読み込み、文字・座標・取得できる書式情報を解析して、怪しい箇所を資料上に重ねて表示します。ファイルや抽出テキストを外部サービスへ送信しません。PPTXも読み取り専用で、元ファイルを編集しません。

## 公開とフィードバック

WindowsでのGit操作からGitHub Pages公開までの手順は [PUBLISHING.md](./PUBLISHING.md) を参照してください。公開前に [辞書・依存物の利用条件](./THIRD_PARTY_NOTICES.md) を維持してください。

誤検出・見逃し、動作不良、改善要望はリポジトリのIssuesで受け付ける構成です。公開サイト上部の「フィードバック」からも報告フォームへ進めます。投稿は公開されるため、機密PDFや校正データは添付せず、自作の再現例をお使いください。

## 起動（Windows）

`start-viewer.cmd` をダブルクリックします。既定ブラウザでビューアが開きます。終了するときは、同時に開いた黒い画面で `Ctrl+C` を押します。

## 開発用の起動

静的ファイルのため、`dist` を任意のローカルHTTPサーバーで配信します。

```powershell
python -m http.server 4173 --directory dist
```

ブラウザで `http://127.0.0.1:4173/` を開きます。

## 現在の検出

- 化学の正表記辞書と一般語辞書での用語候補照合、およびJSONの正規表現規則
- `Cl / CI`、`O / 0`、ギリシャ文字混入などの類似文字
- 通常サイズの数字を含む単純な化学式候補
- 本文、見出し、化学式、単位、番号の簡易分類
- 化学式カテゴリ内のフォント、サイズ、太字、斜体の少数派
- 全候補の一括ハイライト
- 上部の「検索」から開く任意文字列検索（空白、改行、ページ境界を無視）と前後の一致箇所への移動
- PDF本文のドラッグ選択と、選択範囲に対応する役割表示
- 候補選択時の役割表示と、一致文字だけに絞ったハイライト
- 1行に抽出できる反応式の原子数・電荷の比較と、式を入力・修正して検査する欄
- 確認状態（未確認・要修正・問題なし・保留）、メモ、未確認候補への移動
- 選択した文字要素の役割変更と再判定、検査除外と解除
- 共通・中学・高校・勤務先ごとの表記統一ルール
- 更新PDFとのテキスト行比較と、変更箇所・新しい指摘の優先表示
- 図表への参照、図表見出しと問題番号の重複、括弧の対応の簡易検査
- 検査できないページなどの表示

検出は候補提示であり、自動修正は行いません。

## 反応式の検査

「反応式」フィルターに、一致・不一致・判定保留の結果を表示します。候補を選ぶと右側の入力欄に抽出した式が入り、元素ごとの原子数と電荷の合計を確認できます。入力欄の修正は検査用で、PDFを変更しません。

係数、丸括弧・角括弧、結晶水（`CuSO₄·5H₂O`）、状態記号 `(aq)/(s)/(l)/(g)`、イオン、電子に対応します。電荷は `Fe³⁺` または `Fe^3+` と指定します。`Fe3+` は添字と電荷を区別できないため保留します。原子数・電荷の一致は、生成物や反応条件が化学的に正しいことを保証しません。

自動抽出はテキスト式を対象にします。同じページ内で行末が加号・矢印などの場合、位置関係と次行の内容を確認して連結します。別の文字要素になった添字は位置とサイズから復元します。ページをまたぐ式、画像・構造式、空欄問題、矢印上の条件、演算子のない折返しは手動確認が必要です。式の一部が抽出されない場合もあるため、必ずPDF表示と抽出した式を照合してください。

## 確認作業

候補を選んで資料上の位置と判定根拠を確認します。確認状態や判定用の設定はページを開いている間だけ保持します。自動保存・保存データの読み込み・JSON/CSV書き出しはありません。フィードバックはGitHubの入力フォームへ直接進めます。

## 役割・除外・教材ルール

候補またはPDF本文を選択して役割を変更できます。変更・除外の適用単位は、選択文字を含むPDF文字要素全体です。除外は「すべて」または「書式以外」を選択できます。「検査除外の管理」から解除します。正解でない選択肢や誤りを探す問題などの意図的な誤記に使えます。

教材のルールセットは共通・中学・高校・勤務先の4つです。学年による正誤を自動で決める機能ではなく、各セットに `別表記 => 統一する表記` を登録する仕組みです。初期ルールは空欄です。表記規則は行内の文字列一致で判定します。

## 更新PDFと番号・括弧の検査

旧PDFを開いて確認作業を行い、「更新PDFを開く」で新しい版を選びます。追加・変更されたテキスト行はクリックして確認でき、削除された旧行も表示します。同一文字列でも増減した分を扱いますが、変更を1対1で対にする機能や書式・画像の差分検査はありません。

確認状態の引き継ぎは、行と前後の文字列が完全一致し、その文脈が一意で、候補の種類・文字列・判定理由も一致するときに限ります。変更された付近や曖昧な繰り返しは再確認します。更新版への役割変更・除外の自動移植は行いません。

図表の検査は日本語の「図1」「表2」と、行頭の番号に続く見出し（空白のない見出しも含む）を対象にします。画像内の見出し、章ごとの採番、別冊への参照では誤検出する場合があります。図表見出しの重複は同じページ内に限定します。問題番号は行頭の「問1」「問題2」を対象にし、1への採番再開を区切りとして扱います。括弧は日本語の括弧・かぎ括弧を抽出した読み取り順で行・ページをまたいで照合します。半角の数式括弧は単独の警告対象から外し、全角括弧との対応には使います。段組みや意図的な片括弧は手動確認が必要です。

## PPTXの扱い

PPTXはPowerPointや変換サーバーを使わず、同梱した描画ライブラリでブラウザ内に表示します。表示された文字を検索・選択・校正できます。編集機能はありません。SmartArt、特殊な図形、埋め込みフォントなどはPowerPointと完全には同じ表示にならない場合があります。

## 辞書の変更

標準の化学語彙辞書は `dist/dictionaries/school-chemistry.json`（schemaVersion 2）、一般語の照合には `general-runtime.json` を使用します。公開版は再現性を保つため、同梱辞書を自動で使用します。辞書の内容もブラウザ内だけで使用されます。

従来形式の規則辞書（schemaVersion 1、`default.json`）には次の項目を設定できます。

- `terms`: 誤記、推奨表記、理由、重要度
- `patterns`: 正規表現、候補種類、推奨表記、理由、重要度
- `units`: 単位として分類する表記
- `style`: 書式の少数派を判定するための最低標本数と比率

標準起動時の用語判定は正表記辞書を使用し、従来の誤字対 `terms` は使用しません。独自の規則辞書を読み込む場合は従来形式も受け付けます。

## PDF抽出上の扱い

- フォント名を取得できないPDFでは、フォント名を多数派判定に使わず、サイズと取得できる太字・斜体情報で比較します。CMap・標準フォント・WASMの読み込み先は絶対URLにし、ワーカーからも正しい場所を参照します。
- 単位や化学式が複数の文字要素に分割されていても、座標から行を組み立てて規則を照合します。検査では空白・改行とUnicodeの上付き・下付きを保持し、検索では別の連結索引を使います。
- 役割は本文、見出し、化学式、単位、番号、係数、ページ番号、キャプションに分類します。
- 文字列検索は改行・ページ境界を無視します。検査規則は明示的に空白を許容した場合に境界をまたぎます。隣り合う行・ページで分割された用語は、両側の文字列を照合し、正しい辞書用語の保護と誤字候補の提示を行います。間に見出しやページ番号がある場合、段組みなどは完全には扱えません。
- 画像化されたPDFにはOCRが必要です。現在の試作版にはOCRを含みません。

## 実PDFでの誤検出対策（2026-09-30）

高校化学を中心に、実資料8本と既存テストPDF2本、合計183ページで検査しました。数学・音響の資料も、式を化学として誤検出しないかの対照として使用しました。ファイル名や資料中の特定の文を除外する規則はありません。

- 誤字候補は正表記辞書・一般語辞書に加え、派生語、化学語同士の複合語、科学用語の接尾辞、技術語の語末長音の別表記を保護します。既知語に通常の接頭・接尾辞を付けた語は保護します。2026-10-01に一律の末尾文字保護を廃止し、文字重複も検出対象にしました。
- 自動の反応式抽出には化学式らしい構造を求めます。設問番号と式を座標・ラベルで区別し、通常の代数式や定数の定義を候補から外します。原子数・電荷が一致する式は一覧に表示しません。任意の式は「反応式を検査」で確認できます。
- 書式は日本語・欧文を分け、化学式は本文内と独立・列挙の用途を分けて比較します。ページ内の比較を優先し、1ページ当たりの標本が少ない化学式は文書全体でも同じ用途を比較します。単位は同じ単位表記同士を比較します。ページ上部で使われるフォントだからという理由だけで本文まで見出しに分類する処理は廃止しました。
- 見出し階層、番号・係数、数式中の半角括弧の一般的な体裁検査は、根拠が弱いため自動警告を抑えています。上付き・下付きの位置検査、数学全般の正誤、段組み・図中の読み取り順を完全に扱う機能はありません。

検査条件、比較件数、残った候補と限界は `qa/validation-2026-09-30.md` に記録しました。候補数の減少は精度や見逃し率の証明ではありません。テストで用意した主要な誤字・類似文字・フォント・太字・斜体・単位サイズの異常は継続して検出することを確認しました。

`dictionary-sources/audit-corpus.mjs` は、アプリと同じPDF.js抽出と検出処理をローカルで実行し、`qa` に比較結果と抽出キャッシュを保存します。PDFのSHA-256が変わると自動で再抽出します。実行例は `node chemical-proofreading-viewer/dictionary-sources/audit-corpus.mjs after`（ワークスペース直下）。`test-*.mjs` はNode.jsで実行できます。`test-corpus-audit.mjs` は一括解析後の結果を使います。`qa` は配信ディレクトリの外にあります。

## 2026-10-01の追加改善

短い用語（2～3文字）は、同じ長さの化学用語との1文字置換を比較し、付近に化学の語句があり候補が3件以内のときに提示します。単独の語の検査も対象です。一般語の許容辞書は272,355表記になりました。JMdictの一部の意味に付いた注記を理由に、語全体を除外していた生成処理を修正したためです。誤綴り等と注記された表記自体は、引き続き生成元の処理で除外します。

`formulas.mjs` は元素記号・括弧・原子数を解析し、解析できる複数元素の式について通常数字の添字候補を出します。化学の文脈で解析できない式については、1文字の大小文字や類似文字を変更して解析できる候補も提示します。大文字のみの略語や単一元素と数字の組合せなど、変数との区別が難しいものは抑制します。NaCIのように両方が元素記号として解析できる混同は、この新しい方法だけでは決められないため既存の個別規則も残しています。物質名から任意の正しい分子式を決める機能ではありません。

PDFに通常数字として記録された字形が、見た目では下付きになっている場合があります。そのため添字候補は断定を避け、小さい図中ラベルなど根拠が弱い場合は自動検査を抑えます。式の字形が見えることと、内部の文字情報から位置を確定できることは別です。

反応式は同じページで近接・整列した行の末尾に「＋」や矢印などがある場合、続きの行を結合します。対応する文字位置も結合して両行をハイライトします。付近に続きらしい行があるものの結合を確定できない場合は判定保留とします。ページをまたぐ反応式や、演算子を手掛かりにできない折り返しは未完成です。

新しい2ページの検証PDFでは、用語4件・添字2件・元素記号2件・反応式1件の計9件を検出し、正常例は指摘しません。既存10本に新規1本を加えた11本185ページを解析し、7本の回帰テストが成功しました。新規PDFも開発時の回帰検証に使ったため、未知の資料に対する精度測定ではありません。詳細は `qa/validation-2026-10-01.md` を参照してください。

## 公開用辞書への移行（2026-10-02）

標準化学辞書をJMdict・文部科学省・Wikidata由来に再構築しました。正表記を認識するための関連語と、中高の誤字候補を提示する語を `candidateEligible` で区別しています。専門的な関連語は既知語として保護しますが、無条件に訂正候補には出しません。

辞書全体はCC BY-SA 4.0。元のJMdict帰属、文科省資料の出典・加工表示、WikidataのCC0と項目IDを保持しています。旧出版社由来の資料は生成処理に使わず、Gitの公開対象にも含めません。詳しい収録方法・再生成手順は `dist/dictionaries/SCHOOL-DICTIONARY.md` を参照してください。

新規辞書の出典・重複・重要語・候補生成の区別は `node dictionary-sources/test-public-dictionary.mjs` で検証できます。原典を取り直して再生成した場合も実行してください。
